# Data model

The source of truth is `apps/api/prisma/schema.prisma`. This file explains the intent.

## Conventions

- Primary keys are UUIDs generated by the database (`gen_random_uuid()`).
- Tables are snake_case plurals (`@@map`). Columns are snake_case (`@map`).
- **Money is `BigInt` paise.** Quantities and rates are `Decimal` with a fixed scale. Floats are never used for money.
- Timestamps are `timestamptz`. Business dates (bill date, attendance date) are `date` columns, read as calendar dates in India time.
- Every business record will carry `project_id` and `cost_code_id` (from Phase 5), and from Phase 4 the audit log records who changed what.
- Soft "inactive" flags instead of deletes for masters. Financial records are corrected by reversal entries, never edited after export.

## Planned shape (from the assumptions; see ASSUMPTIONS.md)

- **Company / entity:** one legal entity now. Tables that need it will reference a `company` row, so a second GSTIN or JV can be added later without reshaping data.
- **Project hierarchy:** Project → Block (tower/wing/phase, optional) → cost code. Every project is `CONTRACT` or `DEVELOPMENT`.
- **Cost codes:** a company-wide standard list, plus additions per project.
- **Parties:** one party record with roles (creditor, debtor or both), as in Tally.
- **Stock:** held per site (store location) and valued at weighted average cost.
